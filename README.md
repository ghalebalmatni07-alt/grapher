# Graph Plotter — مشروع أندرويد

التطبيق عبارة عن WebView يفتح الملف `app/src/main/assets/index.html` (نفس `grapher.html` بدون أي تعديل).
الأيقونات جاهزة في `app/src/main/res/mipmap-*`.

## الطريقة 1: بناء APK على GitHub (بدون برامج على جهازك)
1. أنشئ مستودعاً جديداً على GitHub وارفع محتويات هذا المجلد كما هي (مع المجلد المخفي `.github`).
2. افتح تبويب **Actions** ← **Build APK** ← **Run workflow**.
3. بعد دقيقتين تقريباً ينزل ملف `GraphPlotter-apk` في آخر الصفحة (Artifacts)، وفيه `app-debug.apk`.

## الطريقة 2: Android Studio
افتح المجلد ← انتظر المزامنة ← **Build ▸ Build APK(s)**.
الملف يطلع في `app/build/outputs/apk/debug/app-debug.apk`.

## ملاحظات
- النسخة الناتجة موقّعة بمفتاح debug، وتصلح للتثبيت المباشر على جهازك. للنشر في Google Play تحتاج نسخة release بمفتاحك الخاص.
- لتثبيت APK من خارج المتجر فعّل "التثبيت من مصادر غير معروفة" لمتصفحك أو مدير الملفات.
- خطوط Google في الصفحة تُحمَّل من الإنترنت، وبدون اتصال يستعمل التطبيق الخطوط الاحتياطية المعرّفة في الملف.
